## Add to Nuvio

1. Open **Nuvio** and go to **Settings → Plugins**.
2. Add the manifest URL below.
3. Enable the providers you want to use.

```text
https://raw.githubusercontent.com/A2R14N/nuvio-providers-ro/refs/heads/main/manifest.json
```

> [!TIP]
> You only need to add the manifest once. Nuvio keeps the collection updated automatically.
